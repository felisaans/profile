Automatic Parking System

Team project

An Arduino-based parking gate for a miniature parking lot. An ultrasonic sensor detects a car, a servo opens the barrier while LEDs show the status, and a laptop plays a spoken welcome. When the lot is full, the gate stays shut, a buzzer sounds and the laptop announces that parking is full.

Hardware
Arduino UNO, HC-SR04, servo, LEDs, buzzer
Software
Arduino C++, Python (pyserial)
Team
Group of 5 classmates
Next steps
Exit gate, RFID payment, IoT monitoring
